This keystore signed every Ky Fitness APK you have installed (phone, watch, watch face).
Android only installs an update over an existing app if it is signed with the SAME key.

Keep a copy of ky-fitness-signing.keystore somewhere safe (cloud drive or password manager).
If you lose it you must uninstall the apps and reinstall, which erases their data.

Keystore details (Android debug key): store password 'android', key alias 'androiddebugkey', key password 'android'.
This is a development key: fine for personal sideloading. Publish to the Play Store with a new release key.

Release builds do NOT use this key. They use a separate upload key described in keystore.properties (see keystore.properties.example).
